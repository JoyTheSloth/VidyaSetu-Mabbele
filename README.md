# Bhaktivedanta Institute Mission School — Public Website

This is the standalone, decoupled public website for **Bhaktivedanta Institute Mission Hr. Sec. School (CBSE Affiliated)**.

## 🌟 Highlights

- **Vedic Heritage & Classical Aesthetics**: Ivy League typography, hero carousel, Atal Tinkering STEM robotics lab showcase, Saraswati Central Library, and athletic arena.
- **Slidable Events & Notices**: Real-time official bulletins with interactive left/right navigation and touch swipe.
- **Admissions Inquiry Modal**: Lead capture and fee structure overview.
- **Direct Portal Integration**: One-click launch buttons directly targeting the Vidyasetu ERP portal (`http://localhost:5174`).

---

## 🚀 Development Commands

```bash
# Start the local development server (Port 5173)
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

- **Local URL**: `http://localhost:5173`
- **Connected Portal URL**: `http://localhost:5174` (Configurable via `VITE_PORTAL_URL`)
